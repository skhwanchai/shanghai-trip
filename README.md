# Shanghai 上海 · ทริป 7–15 พ.ย. 2026

แอปท่องเที่ยวส่วนตัว (PWA) ใช้ออฟไลน์ได้ ไม่พึ่ง Google / CDN ภายนอก

## ขึ้น GitHub Pages
1. สร้าง repo ใหม่ อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons` และ `fonts`)
2. Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save
3. รอ 1–2 นาที เปิด `https://skhwanchai.github.io/shanghai-trip/`

## ก่อนบิน (สำคัญ)
- เปิดลิงก์บนมือถือตอนอยู่ไทย 1 ครั้ง แล้ว **Share → Add to Home Screen** (iPhone ใช้ Safari)
- เปิดจากไอคอนหน้าจอโฮมอีกครั้ง ลองปิดเน็ตแล้วเปิดดูว่ายังใช้ได้
- ในจีน GitHub เข้าได้ไม่แน่นอน แต่แอปทำงานจากที่เก็บไว้ในเครื่อง

## แก้ข้อมูล
- แผน สถานที่ ประโยค เช็กลิสต์ อยู่ใน `data.js` ทั้งหมด
- พิกัดหมุดบนแผนที่คือช่อง `ll: [ละติจูด, ลองจิจูด]` ของแต่ละสถานที่ (หาได้จากการกดค้างใน Apple Maps)
- แก้แล้วให้เปลี่ยนเลข `VERSION` ใน `sw.js` (เช่น `sh26-v2`) มือถือจะโหลดของใหม่ตอนมีเน็ต
- ที่พักอยู่ใน `HOTELS` ท้าย `data.js` (ชื่อโรงแรมและวันพักจะเห็นได้ใน repo สาธารณะ)
- เที่ยวบิน รายจ่าย เช็กลิสต์ที่ติ๊ก เก็บในเครื่องเท่านั้น ไม่ขึ้น GitHub

## รูป
- รูปสถานที่มาจาก Unsplash (ใช้ฟรีตาม Unsplash License) มีชื่อช่างภาพใต้รูปทุกรูป แก้ได้ที่ช่อง `photo` ใน `data.js`
- รูปที่ระบุว่า "ภาพบรรยากาศ" ไม่ใช่จุดนั้นเป๊ะ
- เปิดแอปตอนอยู่ไทยแล้วรอสักครู่ แอปจะเก็บรูปทั้งหมดไว้ในเครื่อง ไปจีนแล้วดูได้แม้ไม่มีเน็ต
- รูปที่ถ่ายเองในหน้ารายละเอียด เก็บในมือถือเครื่องนั้นเท่านั้น ไม่ขึ้น GitHub

## ความเป็นส่วนตัว
repo สาธารณะใครก็เห็น อย่าใส่เลขพาสปอร์ต เลขจอง หรือเบอร์ส่วนตัวใน `data.js`
